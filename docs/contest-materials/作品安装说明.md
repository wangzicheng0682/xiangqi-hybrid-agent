# 作品安装说明

## 一、环境要求

### 1.1 硬件要求

| 组件 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 双核 2GHz | 四核 3GHz+ |

| 硬盘 | 10GB可用空间 | SSD 20GB+ |

## 四、后端安装

### 4.1 创建Python虚拟环境（推荐）

```bash
# 进入项目目录
cd d:\xiangqi-hybrid-agent

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows CMD:
venv\Scripts\activate.bat
# Windows PowerShell:
venv\Scripts\Activate.ps1
# Git Bash:
source venv/Scripts/activate

# 验证激活
# 提示符前应出现 (venv)
```

### 4.2 安装Python依赖

```bash
# 激活虚拟环境后执行
pip install -r requirements.txt
```


```bash

```

### 4.3 安装Pikafish引擎

**引擎文件已内置在项目中：**
```
data/engine/
├── pikafish.exe           # Windows可执行文件
└── uci_options.json       # UCI配置
```

### 4.4 配置向量数据库目录（RAG系统）

RAG系统使用ChromaDB存储向量数据，需要创建数据目录：

```bash
# 进入项目目录
cd d:\xiangqi-hybrid-agent

# 创建向量数据库目录
mkdir -p data\vector_db\chroma

# 目录结构
data/
├── vector_db/
│   └── chroma/           # ChromaDB持久化目录
├── engine/               # Pikafish引擎
├── init_data/            # 棋谱数据
└── games/               # 对局数据库
```

**说明：** 首次访问RAG功能时，系统会自动索引80+棋理原则，无需手动操作。

**如果需要重新下载：**
```
访问 https://github.com/official-pikafish/pikafish/releases
下载最新版本的 pikafish-windows-x86-64.exe
放置到 data/engine/ 目录
```

### 4.4 配置环境变量（可选）

在项目根目录创建 `.env` 文件：

```env
# API配置
API_HOST=0.0.0.0

# LLM配置（根据实际情况修改）
LLM_API_KEY=your_api_key_here

# Neo4j配置（可选）
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your_password

# Pikafish引擎路径
```

## 八、快速启动命令汇总

### 8.1 完整启动流程

```bash
# 1. 打开终端，进入项目目录
cd d:\xiangqi-hybrid-agent

# 2. 激活Python虚拟环境
venv\Scripts\activate.bat

# 3. 启动后端API（后台运行）
start /B python -m uvicorn api.main:app --host 0.0.0.0 --port 8002

# 4. 新开终端，进入前端目录
cd d:\xiangqi-hybrid-agent\frontend

# 5. 启动前端开发服务器
npm run dev

# 6. 浏览器打开 http://localhost:3001
```

### 8.2 一键启动脚本

创建 `start.bat` 文件：

```batch
@echo off
title 象棋AI混合代理系统

cd /d %~dp0

echo 启动Python虚拟环境...
call venv\Scripts\activate.bat

echo 启动后端API服务...
start "Xiangqi API" python -m uvicorn api.main:app --host 0.0.0.0 --port 8002

echo 等待服务启动...
timeout /t 3

cd frontend
echo 启动前端开发服务器...
start "Xiangqi Frontend" npm run dev

echo.
echo 请访问: http://localhost:3001
pause
```

## 十、常见问题

### 10.1 Python相关问题

**问题：pip install 报错 "Microsoft Visual C++ 14.0 is required"**
```
解决方案：
1. 下载 Visual Studio Build Tools
2. 安装 "C++ 生成工具" 工作负载
3. 重新运行 pip install
```

**问题：Python版本不兼容**
```
解决方案：
1. 卸载当前Python
2. 安装 Python 3.10 或更高版本
3. 重新安装依赖
```

### 10.2 Node.js相关问题

**问题：npm install 速度慢**
```
解决方案：
1. 使用国内镜像
   npm config set registry https://registry.npmmirror.com
2. 清理缓存后重试
   npm cache clean --force
   npm install
```

**问题：vite 启动失败**
```
解决方案：
1. 检查端口占用
   netstat -ano | findstr 3000
2. 杀死占用进程或更换端口
```

### 10.3 后端相关问题

**问题：Pikafish引擎无法启动**
```
解决方案：
1. 确认引擎文件存在
   dir data\engine\
2. 检查引擎文件权限
3. 手动测试引擎
   data\engine\pikafish.exe
   输入: uci
   输入: isready
   输入: quit
```

**问题：API响应500错误**
```
解决方案：
1. 检查日志输出
2. 确认虚拟环境已激活
3. 重新安装依赖
   pip install -r requirements.txt --force-reinstall
```

### 10.4 前端相关问题

**问题：WebGL渲染异常**
```
解决方案：
1. 更新显卡驱动
2. 确认浏览器支持WebGL2
   chrome://gpu/
3. 禁用硬件加速（测试用）
   设置 → 高级 → 系统 → 禁用硬件加速
```

**问题：组件样式异常**
```
解决方案：
1. 清除浏览器缓存
2. 重新构建
   npm run build
3. 检查Tailwind配置
```

### 10.5 Neo4j相关问题

**问题：Neo4j无法连接**
```
解决方案：
1. 确认Neo4j服务已启动
   neo4j status
2. 检查端口占用
   netstat -ano | findstr 7687
3. 检查认证信息
```
