# 前端 Plan 规范

> 记录前端未成熟但打算去做的想法。

---

## 文档结构

每个 Plan 必须包含：

```markdown
# {标题}

## 背景
为什么有这个想法？要解决什么问题？

## 核心方案
具体打算怎么做？

## 待验证问题
有哪些不确定的地方？

## 状态
- [ ] 构思中
- [ ] 验证中
- [ ] 准备实现
- [ ] 已实现
- [ ] 已搁置
```

---

## 命名规范

```
{序号}-{简短标题}.md
```

示例：
- `001-dark-mode.md`
- `002-mobile-support.md`

序号使用三位数字，从001开始。

---

## 状态流转

```
构思中 → 验证中 → 准备实现 → 已实现
                ↓
             已搁置
```
