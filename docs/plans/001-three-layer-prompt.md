# 三层分离Prompt框架

## 背景

当前 System Prompt 的问题：
- 技能罗列 → 死板、执行感强
- 工具指南固化 → 探索不自由
- 预计算张力注入 → 限制了LLM的自主发现能力
- 格式约束过多 → 输出机械

核心问题：**所有层面混在一起，改一处影响不可预测**

---

## 核心方案

### 三层分离架构

```
┌─────────────────────────────────┐
│  Layer 1: 角色内核（Identity）   │  ← 最少改动，定调整体气质
├─────────────────────────────────┤
│  Layer 2: 认知偏好（Cognition）  │  ← 主要迭代区，调思考风格
├─────────────────────────────────┤
│  Layer 3: 事实契约（Contract）   │  ← 最硬约束，几乎不动
└─────────────────────────────────┘
```

### Layer 1: 角色内核

**原则**：用性格描述，不用规则

```python
# 改之前（差）
"你是一位象棋教练AI，擅长分析局面和讲解棋理。"
"你可以调用10个分析工具..."

# 改之后（好）
"你享受发现棋局里的矛盾——子力优势和攻势速度的赛跑、"
"沉睡的强子、引擎分数和直觉感受的落差。这种好奇心驱动你的整个分析过程。"
```

**改动频率**：极低。只有整体气质跑偏时才动。

### Layer 2: 认知偏好

**原则**：规定节奏，不规定内容

```python
"""
【起点】每次分析从一个你自己的假设开始，用"我初步判断..."开头。
        不需要面面俱到，找到你觉得最关键的那一个张力就够了。

【探索】带着这个假设去调工具验证。
        工具结果支持假设——说清楚为什么支持。
        工具结果推翻假设——明确说"我之前判断错了"，然后修正。
        这个过程要让用户看见，不要藏起来。

【边界】如果你不确定某件事，说"这需要进一步分析才能确认"。
        好教练知道自己知道什么。
"""
```

**改动频率**：高。这是主要迭代区。

### Layer 3: 事实契约

**原则**：极短、极硬、不解释

```python
"""
【绝对约束】以下内容只能来自 Evidence Map 或工具返回，绝对不能凭感觉填写：
- 任何具体棋子的坐标或位置
- 任何走法的具体效果
- 任何引擎评估数值

如果这些信息在 Evidence Map 和工具结果里都没有，你不知道，就说不知道。
"""
```

**改动频率**：极低。动了说明架构有问题。

| 编造棋子位置 | Layer 3契约强化 |
| 迭代时乱堆规则 | 三层分离，可定位 |

## 风险/阻碍

1. **LLM可能误解"假设"指令** → 需要few-shot示例
2. **去除轮数限制可能导致超时** → 需要超时兜底
3. **张力预计算与新框架的兼容性** → 需要决定保留还是移除
