## 一、设计目标

### 1.1 核心定位

事实识别器只做**一件事**：从引擎获取客观事实，不做任何主观推断。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **引擎真值唯一** | bestmove/score/pv 是唯一可信来源 |
| **零自研计算** | 禁止自行计算"攻击"、"防御"、"威胁" |
| **间接推断** | 所有判断必须通过引擎评估变化间接推断 |
| **原始输出** | 只输出引擎返回的原始数据 |

### 2.2 数据结构

```python
from dataclasses import dataclass
from typing import List, Optional, Dict
from enum import Enum

class FactType(Enum):
    """事实类型"""
    BEST_MOVE = "best_move"           # 最优走法
    SCORE = "score"                   # 评估分数
    PV = "pv"                         # 主要变例
    DEPTH = "depth"                   # 分析深度
    NODES = "nodes"                   # 搜索节点数
    TIME = "time"                     # 分析时间

@dataclass
class EngineOutput:
    """引擎原始输出"""
    bestmove: Optional[str]           # 最优走法（UCI格式）
    score: Optional[int]              # 评估分数（cp或mate）
    score_type: str                   # "cp" 或 "mate"
    pv: List[str]                     # 主要变例（走法列表）
    depth: int                        # 分析深度
    nodes: int                        # 搜索节点数
    time_ms: int                      # 分析时间（毫秒）
    
@dataclass
class PositionFacts:
    """局面事实集合"""
    fen: str                          # 输入FEN
    engine_output: EngineOutput       # 引擎原始输出
    
    # 以下字段均由引擎输出派生，不做额外计算
    is_winning: Optional[bool]        # 是否优势（score > 200）
    is_losing: Optional[bool]         # 是否劣势（score < -200）
    is_equal: Optional[bool]          # 是否均势（-100 < score < 100）
    has_forced_mate: Optional[bool]   # 是否有强制杀棋
    mate_in: Optional[int]            # 几步杀（如有）
    
@dataclass
class MoveFacts:
    """走法事实集合"""
    fen: str                          # 原始局面FEN
    move: str                         # 分析的走法
    engine_output: EngineOutput       # 引擎分析结果
    
    # 走法评估
    is_best_move: bool                # 是否是最优走法
    score_diff: int                   # 与最优走法的分差
    is_blunder: bool                  # 是否漏着（分差 > 200）
    is_mistake: bool                  # 是否错着（分差 100-200）
    is_inaccuracy: bool               # 是否不精确（分差 50-100）
    
@dataclass
class PositionComparison:
    """局面比较结果"""
    fen_before: str                   # 变化前
    fen_after: str                    # 变化后
    facts_before: PositionFacts       # 变化前事实
    facts_after: PositionFacts        # 变化后事实
    
    # 比较结果
    score_change: int                 # 分数变化
    advantage_changed: bool           # 优势是否转换
    is_critical_moment: bool          # 是否关键局面（分数剧变）
```

## 三、实现策略

### 3.1 基于引擎的实现

```python
class PikafishFactExtractor(FactExtractor):
    """
    基于Pikafish引擎的事实识别器
    """
    
    def __init__(self, engine_path: str):
        self.engine = PikafishEngine(engine_path)
    
    def extract_facts(self, fen: str, depth: int = 20) -> PositionFacts:
        # 调用引擎分析
        engine_result = self.engine.analyze(fen, depth=depth)
        
        # 解析引擎输出（不做任何额外计算）
        engine_output = self._parse_engine_output(engine_result)
        
        # 仅从引擎输出派生事实
        return PositionFacts(
            fen=fen,
            engine_output=engine_output,
            is_winning=engine_output.score > 200 if engine_output.score else None,
            is_losing=engine_output.score < -200 if engine_output.score else None,
            is_equal=abs(engine_output.score) < 100 if engine_output.score else None,
            has_forced_mate=engine_output.score_type == "mate" if engine_output.score else None,
            mate_in=engine_output.score if engine_output.score_type == "mate" else None
        )
    
    def extract_move_facts(self, fen: str, move: str, depth: int = 20) -> MoveFacts:
        # 获取当前局面最优走法
        current_facts = self.extract_facts(fen, depth)
        best_move = current_facts.engine_output.bestmove
        
        # 执行走法后的局面
        new_fen = self._apply_move(fen, move)
        new_facts = self.extract_facts(new_fen, depth)
        
        # 计算分差（从当前方视角）
        score_diff = abs(new_facts.engine_output.score or 0) - abs(current_facts.engine_output.score or 0)
        
        return MoveFacts(
            fen=fen,
            move=move,
            engine_output=new_facts.engine_output,
            is_best_move=(move == best_move),
            score_diff=score_diff,
            is_blunder=score_diff > 200,
            is_mistake=100 < score_diff <= 200,
            is_inaccuracy=50 < score_diff <= 100
        )
```

### 3.2 禁止事项

❌ **严禁以下行为**：

| 禁止项 | 原因 | 替代方案 |
|--------|------|----------|
| 自行计算"攻击列表" | 炮攻击逻辑复杂，容易出错 | 通过引擎评估分变化推断 |
| 自行计算"被攻击"状态 | 需要完整的攻击检测逻辑 | 通过PV线索间接推断 |
| 自行计算"防御"关系 | 防御逻辑依赖攻击检测 | 不计算，只报告引擎分数 |
| 生成"无根子"标签 | 无法验证，容易产生错误 | 禁止生成此类标签 |
| 生成"马腿受阻"标签 | 己方棋子别马腿是正常情况 | 禁止生成此类标签 |
| 生成"威胁"标签 | 威胁判断主观性强 | 通过PV中的将军线索推断 |
| 生成任何无法验证的语义标签 | 缺乏真值来源 | 只输出引擎原始数据 |

## 四、间接推断策略

### 4.1 如何不计算攻击也能判断威胁

**错误做法**（已归档）：
```python
# 错误：自行扫描棋盘计算攻击
def is_piece_attacked(piece_pos, board):
    for enemy in get_enemy_pieces(board):
        if can_attack(enemy, piece_pos):  # 复杂的攻击计算
            return True
```

**正确做法**：
```python
# 正确：通过引擎PV推断威胁
def has_threat(facts: PositionFacts) -> bool:
    """
    通过PV中的将军线索推断是否存在威胁
    不自行计算攻击
    """
    pv = facts.engine_output.pv
    # 如果PV中包含将军或杀棋，说明存在威胁
    # 具体实现通过引擎输出的check/mate信息
    return facts.engine_output.score_type == "mate" or "+" in str(pv)
```

### 4.2 如何不计算防御也能评估安全性

**错误做法**（已归档）：
```python
# 错误：自行计算防御关系
def is_piece_defended(piece_pos, board):
    for ally in get_ally_pieces(board):
        if can_defend(ally, piece_pos):  # 复杂的防御计算
            return True
```

**正确做法**：
```python
# 正确：通过引擎评估分推断安全性
def evaluate_safety(facts: PositionFacts) -> str:
    """
    通过引擎评估分推断局面安全性
    不自行计算防御
    """
    score = facts.engine_output.score
    if score is None:
        return "unknown"
    
    # 引擎分数已经综合考虑了所有因素
    if score > 300:
        return "safe"
    elif score < -300:
        return "dangerous"
    else:
        return "balanced"
```

## 五、输出规范

### 5.1 允许的输出

✅ **仅允许输出**：

| 输出类型 | 来源 | 示例 |
|----------|------|------|
| 最优走法 | 引擎 bestmove | "h2e2" |
| 评估分数 | 引擎 score | +150, mate in 3 |
| 主要变例 | 引擎 pv | ["h2e2", "h7e7", ...] |
| 分数变化 | 引擎输出比较 | +50 cp |
| 走法评估 | 与bestmove比较 | is_blunder: true |

### 5.2 禁止的输出

❌ **禁止输出**：

| 禁止输出 | 原因 |
|----------|------|
| "无根子"标签 | 无法验证，曾导致错误泛滥 |
| "马腿受阻"标签 | 己方棋子别马腿是正常情况 |
| "被攻击"标签 | 需要自研攻击计算 |
| "受保护"标签 | 需要自研防御计算 |
| "威胁"标签 | 主观性强，通过PV推断 |
| "攻势"标签 | 主观性强 |
| "防守薄弱"标签 | 主观性强 |
