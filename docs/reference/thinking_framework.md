# 特级大师思维链框架

> 让LLM像特级大师一样分析棋局

**版本**: v1.1
**最后更新**: 2026-03-15

---

## 设计理念

### 核心原则

**阶段感知，抓住主要矛盾**

特级大师分析棋局不是"通用套路"，而是根据局面阶段（开局/中局/残局）切换不同的思维框架：

| 阶段 | 核心矛盾 | 思维重点 |
|------|----------|----------|
| 开局 | 出子与争先 | 快速出动大子，抢占要点 |
| 中局 | 战术与攻防 | 寻找战术机会，攻防转换 |
| 残局 | 兵型与定式 | 兵的升变，理论定式 |

### 为什么从开局做起

1. **标准化程度高** — 开局变化相对固定，有大量定式可参考
2. **评估标准明确** — 出子速度、中心控制、子力活跃度
3. **容易验证效果** — 开局好坏有客观标准
4. **LLM容易掌握** — 规则清晰，不易出错

## 一、开局思维框架（优先实现）

### 1.1 开局十大原则

来源：联网搜索整理的专业象棋知识

| 优先级 | 原则 | 说明 | 常见错误 |
|--------|------|------|----------|
| 1 | **尽早出动大子** | 车、马、炮三类兵种威力最大 | 重复走同一子浪费步数 |
| 2 | **避免子力拥堵** | 注意阵型协调，左右均衡 | 金钩炮开局（新手不易驾驭） |
| 3 | **重视中央控制** | 帅将位于九宫，控制中路是关键 | 飞双边相削弱中路保护 |
| 4 | **避免走动帅将** | 初始位置最安全 | 无意义移动老帅 |
| 5 | **避免孤军深入** | 子力要互相配合 | 开局第一步走过河炮 |
| 6 | **避免浪费步数** | 提高运子效率 | 沿河十八打 |
| 7 | **尽可能活马** | 马受马脚限制，畅通马路是关键 | 马被困在角落 |
| 8 | **发挥车的威力** | 车是最强子 | 缓开车变成不开车 |
| 9 | **开局炮略高于马** | 子力多，马受限，炮有炮架 | 开局用炮换马 |
| 10 | **适当联动士象** | 构筑防线，但不耽误出子 | 过早补士象 |

### 1.2 开局体系分类

#### 中炮类（进攻型）

| 体系 | 描述 | 主要变例 |
|------|------|----------|
| **中炮对屏风马** | 最主流对局体系 | 进三兵、进七兵、急进中兵、五七炮、五八炮 |
| **中炮对反宫马** | 黑方炮8平6限制红马 | 进七兵、五七炮 |
| **顺炮** | 双方同向架中炮 | 直车对横车、横车对直车、缓开车 |
| **列炮** | 双方反向架中炮 | 列炮直车、中途列炮 |

#### 非中炮类（防守/试探型）

| 体系 | 描述 | 特点 |
|------|------|------|
| **飞相局** | 第一步飞相 | 稳健防守，后发制人 |
| **仙人指路** | 第一步挺兵 | 试探性强，可转多种阵型 |
| **起马局** | 第一步起马 | 稳健开局，灵活多变 |
| **过宫炮** | 炮移六路 | 集中火力，需要经验 |

### 1.3 黑方应对中炮四大体系

| 应对 | 走法 | 特点 | 适合人群 |
|------|------|------|----------|
| **屏风马** | 马8进7，马2进3 | 防守稳固，变化丰富 | 所有棋手必修 |
| **反宫马** | 马2进3，炮8平6 | 阵型紧凑，限制对方 | 喜欢防守反击 |
| **顺炮** | 炮8平5 | 对攻激烈，变化直接 | 喜欢对攻 |
| **列炮** | 炮2平5 | 各攻一翼，对攻性强 | 有经验棋手 |

### 1.4 开局分析流程

```
【开局分析框架】

Step 1: 判断开局阶段
├── 回合数 ≤ 15 且 棋子总数 ≥ 26 → 开局阶段
└── 否则 → 进入中局分析

Step 2: 出子效率分析
├── 红方已出动大子数量
├── 黑方已出动大子数量
├── 哪方出子更快？
└── 有没有重复走同一子？

Step 3: 中心控制分析
├── 谁控制5线（中路）？
├── 兵型结构是否健康？
└── 有没有挺兵争中？

Step 4: 子力活跃度分析
├── 马是否有根？（马脚问题）
├── 炮是否有架？（炮架问题）
├── 车是否通路？
└── 有没有压死的子？

Step 5: 先手争夺分析
├── 谁在主动进攻？
├── 谁在被动防守？
└── 有没有得先/失先？

Step 6: 开局定式识别（可选）
├── 是否进入某种定式？
│   ├── 中炮对屏风马
│   ├── 仙人指路
│   ├── 飞相局
│   └── ...更多定式
└── 有没有偏离谱着？
```

### 1.3 开局分析问题清单

LLM在分析开局时，应该依次回答以下问题：

```yaml
出子效率:
  - 红方已出动几枚大子？
  - 黑方已出动几枚大子？
  - 有没有重复走同一子？（效率问题）
  - 有没有出子顺序不当？

中心控制:
  - 谁控制中路？
  - 兵挺到什么位置？
  - 有没有弃兵争先？

子力活跃:
  - 马是否有根？
  - 炮是否有架？
  - 车是否占领开放线？
  - 有没有位置不好的子？

先手争夺:
  - 当前谁握有先手？
  - 有没有暗藏的战术？
  - 下一步应该争什么？
```

📊 出子效率

### 2.1 中局五大原则

| 优先级 | 原则 | 说明 |
|--------|------|------|
| 1 | **战术优先** | 先看有没有将军/杀棋/抽子 |
| 2 | **子力对比** | 评估双方子力平衡 |
| 3 | **弱点攻击** | 寻找并攻击对方弱点 |
| 4 | **攻防转换** | 判断进攻还是防守 |
| 5 | **战术组合** | 寻找弃子攻杀机会 |

### 2.2 中局分析流程

```
【中局分析框架】

Step 1: 战术扫描（最高优先级）
├── 有没有将军？
├── 有没有杀棋？
├── 有没有捉子/抽子？
├── 有没有闪击/牵制？
└── 有没有战术组合？

Step 2: 子力对比
├── 双方子力是否平衡？
├── 谁多子？谁少子？
└── 有没有兑子机会？

Step 3: 弱点识别
├── 哪方有"无根子"？
├── 哪方兵型有缺陷？
├── 哪方老帅不安全？
└── 哪方底线有漏洞？

Step 4: 攻防判断
├── 谁在进攻？
├── 谁在防守？
└── 攻防是否平衡？

Step 5: 战术机会
├── 有没有弃子攻杀？
├── 有没有先弃后取？
└── 有没有长将求和？
```

## 四、阶段检测器

### 4.1 阶段判断规则

```python
def detect_phase(fen: str, move_count: int) -> str:
    """
    检测局面阶段

    规则：
    - 开局：回合数 ≤ 15 且 棋子总数 ≥ 26
    - 残局：棋子总数 ≤ 14
    - 中局：其他情况
    """
    total_pieces = count_pieces(fen)

    if move_count <= 15 and total_pieces >= 26:
        return "opening"
    elif total_pieces <= 14:
        return "endgame"
    else:
        return "middlegame"
```

### 4.2 阶段特征

| 阶段 | 回合数 | 棋子总数 | 兵的状态 |
|------|--------|----------|----------|
| 开局 | 1-15 | ≥26 | 兵基本完整 |
| 中局 | 10-40 | 15-27 | 兵开始减少 |
| 残局 | >30 | ≤14 | 兵很少或有过河兵 |

## 五、LLM System Prompt 集成

### 5.1 动态Prompt注入

根据检测到的阶段，动态注入对应的思维框架：

```python
def build_system_prompt(fen: str, move_count: int) -> str:
    phase = detect_phase(fen, move_count)

    base_prompt = """你是象棋教练AI，擅长分析局面和讲解棋理。"""

    if phase == "opening":
        phase_prompt = OPENING_THINKING_TEMPLATE
    elif phase == "middlegame":
        phase_prompt = MIDDLEGAME_THINKING_TEMPLATE
    else:
        phase_prompt = ENDGAME_THINKING_TEMPLATE

    return base_prompt + "\n\n" + phase_prompt
```
