## 概述

本文档包含9个完整的棋局分析示例，每个示例展示：
1. **思维链** — 像特级大师一样的分析思路
2. **工具调用** — 调用哪个工具、为什么、返回什么
3. **总结输出** — 标准化的教练建议格式

**用途**：
- 现场演示
- Agent调教（Few-shot学习）

## 一、开局示例（3个）

### 示例1：中炮进三兵对屏风马

**局面信息**：
```
阶段：开局（第5回合）
FEN：rnbakabnr/9/1c5c1/p1p1p1p1p/9/9/P1P1P1P1P/1C5C1/9/RNBAKABNR w - - 0 5
特点：双方出子均衡，红方中路有控制
```

**思维链**：
```
【阶段识别】开局（第5回合，32子完整）
【开局定式】可能是中炮进三兵对屏风马的前奏

【开局原则检查】
1. 出子效率：红方已出炮+马，黑方已出双马，双方相当
2. 中路控制：红炮瞄住中卒，黑马保护
3. 马炮活跃：红马正马位置，黑双马屏风
4. 先手判断：红方先手架炮，稍占主动
```

**工具调用**：

| 步骤 | 工具 | 输入 | 输出 | 理由 |
|------|------|------|------|------|
| 1 | `analyze_position_strategy` | fen | {阶段: "开局", 主动权: "红方稍先"} | 先了解整体 |
| 2 | `engine_alternatives` | fen, top_n=3 | 兵三进一(+0.3), 马八进七(+0.2), 车一平二(+0.2) | 了解引擎推荐 |

**总结输出**：
```
【出子效率】红方已出动炮、马共2子；黑方已出动双马共2子，双方出子相当
【中心控制】红炮(5,2)瞄准黑方中卒，黑双马形成屏风保护中路
【子力活跃】红马正马位置可攻可守，黑双马屏风阵型稳固
【先手判断】红方稍先，因为先手架中炮，有中路控制权
【教练建议】红方可选择兵三进一继续挺进，或马八进七稳固阵型，保持先手
```

```

FEN：rn1akabnr/9/1c4c2/p1p1p1p1p/9/9/P1P1P1P1P/1C4C2/9/RN1AKABNR w - - 0 6
特点：顺炮局，红直车对黑横车，对攻激烈
```

**思维链**：
```
【阶段识别】开局（第6回合）
【定式识别】顺炮直车对横车

【开局分析】
1. 双方同架中炮，中路对攻
2. 红方直车快速亮出，黑方准备横车
3. 顺炮局变化直接，对攻性强
4. 需要精确计算，避免失误
```

**工具调用**：

| 步骤 | 工具 | 输入 | 输出 | 理由 |
|------|------|------|------|------|
| 1 | `get_piece_attacks` | "红车" | 攻击黑卒(2,7)、空位(2,8) | 了解红车控制范围 |
| 2 | `compare_moves` | ["h2h6", "h2e2"] | 车二进六(+0.4), 车二平五(+0.2) | 顺炮局需积极进攻 |

**总结输出**：
```
【定式识别】顺炮直车对横车，经典对攻开局
【对攻态势】双方中路对攻激烈，红直车已亮出，黑方准备横车
【关键选择】红方可选择车二进六过河压制，积极进攻
【教练建议】顺炮局需要精确，红方应积极进攻但不可冒进
```

### 示例4：捉双战术（马踩双）

**局面信息**：
```
阶段：中局（第12回合）
FEN：r1bakabnr/9/2n3c2/p1p1p1p1p/9/4N4/P1P1P1P1P/1C3N3/9/R1BAKAB1R w - - 0 12
特点：红马位置优越，可同时攻击两个目标
```

**思维链**：
```
【阶段识别】中局（第12回合，子力开始减少）
【战术扫描】
1. 红马(5,6)位置优越，在中心要点
2. 可同时攻击黑车和黑炮
3. 这是经典的"捉双"战术
4. 黑方只能保一个，必然丢子
```

**工具调用**：

| 步骤 | 工具 | 输入 | 输出 | 理由 |
|------|------|------|------|------|
| 1 | `get_piece_attacks` | "红马(5,6)" | 攻击黑车、黑炮、空位 | 确认可攻击目标 |
| 2 | `get_forcing_sequence` | "马五进七", depth=4 | 红方得子 | 确认战术成立 |
| 3 | `engine_deep_analysis` | fen, depth=20 | 最佳走法: 马五进七, 评估: +2.5 | 引擎验证 |

**总结输出**：
```
【战术发现】红马(5,6)可同时攻击黑车(1,10)和黑炮(3,8)
【战术类型】捉双战术（马踩双）
【战术结果】黑方只能保一个，红方必然得子
【教练建议】立即走马五进七捉双，这是必得子的战术机会，不要错过！
```

### 示例5：弃子攻杀（弃马抢攻）

```
阶段：中局（第15回合）
FEN：r2ak1b1r/9/2n3n2/p1p1p1p1p/9/4N4/P1P1P1P1P/1C3N3/9/R1BAKAB1R w - - 0 15
特点：红马可弃子打开黑方防线
```

**思维链**：
```
【阶段识别】中局（第15回合）
【战术扫描】
1. 红马(5,6)位置突出，但有危险
2. 可选择弃子攻杀，打开黑方防线
3. 弃子后后续攻势需要计算
4. 风险与收益并存
```

**工具调用**：

| 步骤 | 工具 | 输入 | 输出 | 理由 |
|------|------|------|------|------|
| 1 | `analyze_move` | "e5f7" | 质量: aggressive, 物质损失-450, 攻势+600 | 评估风险收益 |
| 2 | `engine_deep_analysis` | fen, depth=25 | 评估: +1.2, 弃子攻杀成立 | 引擎验证 |
| 3 | `get_forcing_sequence` | "e5f7", depth=5 | 红方形成强大攻势 | 确认后续攻势 |

**总结输出**：
```
【战术发现】红马可弃子(马五进六)打开黑方防线
【风险评估】弃马损失450分，但后续攻势价值600分以上
【引擎观点】引擎评估+1.2，支持弃子攻杀
【教练建议】如果计算清晰、后续攻势明确，可果断弃子攻杀！但若不确定，先稳固阵型
```

## 四、使用方式

### 代码调用

```python
from core.llm.fewshot_examples import (
    get_fewshot_prompt,
    get_all_examples,
    format_example_for_display,
)

# 获取开局阶段的Few-shot Prompt
prompt = get_fewshot_prompt("opening", count=1)

# 获取所有示例
all_examples = get_all_examples()

# 格式化显示
print(format_example_for_display(all_examples[0]))
```

### 演示脚本

```python
# 演示脚本：逐个展示示例
for example in get_all_examples():
    print(format_example_for_display(example))
    input("按Enter继续...")
```
