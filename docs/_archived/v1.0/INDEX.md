## 🏗️ 项目架构

基于19万局PGN + Pikafish引擎的三层架构：

```
┌─────────────────────────────────────┐
│  上层：LLM讲解层                     │
│  - Evidence Map约束                  │
│  - 零幻觉讲解                        │
└─────────────────────────────────────┘
                   ↑
┌─────────────────────────────────────┐
│  中层：Transformer特征层             │
│  - 256维高维检索向量                 │
│  - 20个战术标签置信度                │
└─────────────────────────────────────┘
                   ↑
┌─────────────────────────────────────┐
│  底层：规则事实层                    │
│  - Pikafish引擎真值                  │
│  - 六大层级战术标签                  │
└─────────────────────────────────────┘
```

xiangqi-hybrid-agent/
