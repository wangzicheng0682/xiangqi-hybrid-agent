## 一、设计目标

### 1.1 核心定位

规则检查器只做**一件事**：判断走法是否合法。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **单一职责** | 仅做合法性校验，不计算攻击/防御/评估 |
| **真值来源** | 以 Pikafish 引擎输出为唯一合法走法来源 |
| **零自研逻辑** | 不自行实现象棋规则计算（避免Bug） |
| **输入输出明确** | FEN → 合法走法列表(mask) |

### 2.2 数据结构

```python
from dataclasses import dataclass
from typing import List, Dict
import numpy as np

@dataclass
class LegalMove:
    """单个合法走法"""
    from_square: str      # 起始位置（如 "h2"）

    is_check: bool                    # 是否被将军
    is_checkmate: bool                # 是否被将死
    is_stalemate: bool                # 是否逼和
```

## 三、实现策略

### 3.1 基于引擎的实现（推荐）

```python
class PikafishRuleEngine(RuleEngine):
    """
    基于Pikafish引擎的规则检查器
    不自行计算，完全依赖引擎输出
    """
    
    def __init__(self, engine_path: str):
        self.engine = PikafishEngine(engine_path)
    
    def get_legal_moves(self, fen: str) -> LegalMovesResult:
        # 直接调用引擎获取合法走法
        engine_output = self.engine.get_legal_moves(fen)
        
        # 解析引擎输出，不添加任何自研逻辑
        moves = self._parse_engine_moves(engine_output)
        
        return LegalMovesResult(
            fen=fen,
            side_to_move=self._parse_side(fen),
            moves=moves,
            count=len(moves),
            is_check=self._check_is_check(fen),
            is_checkmate=len(moves) == 0 and self._check_is_check(fen),
            is_stalemate=len(moves) == 0 and not self._check_is_check(fen)
        )
```

### 3.2 禁止事项

❌ **严禁以下行为**：

| 禁止项 | 原因 |
|--------|------|
| 自行计算"攻击列表" | 炮攻击逻辑复杂，容易出错 |
| 自行计算"被攻击"状态 | 需要完整的攻击检测逻辑 |
| 自行计算"防御"关系 | 防御逻辑依赖攻击检测 |
| 生成"无根子"标签 | 无法验证，容易产生错误 |
| 生成"马腿受阻"标签 | 己方棋子别马腿是正常情况 |
| 生成任何语义标签 | 超出规则检查器职责范围 |

## 七、风险提示

### 7.1 已知风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 引擎依赖 | 引擎不可用时功能失效 | 提供mock引擎降级方案 |

### 7.2 设计约束

⚠️ **严格遵守**：
1. 不自行实现任何象棋规则计算
2. 不生成任何语义标签
3. 不做任何局面评估
4. 引擎输出是唯一可信来源
