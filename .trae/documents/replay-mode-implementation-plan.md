# 打棋谱模式实现计划

## 概述

新增"打棋谱"模式，支持从Neo4j数据库选择对局或导入PGN文件进行复盘学习。

## 数据库现状

- 对局数: 199,213
- 局面数: 7,906,885
- 棋手数: 36,989
- 走法数: 12,746,666

## 实现步骤

### 第一阶段：后端API扩展

#### 1.1 新增对局搜索API
- 文件: `api/main.py`
- 新增端点:
  - `GET /api/games/search` - 搜索对局（按棋手名、赛事名）
  - `GET /api/games/{game_id}` - 获取对局详情（包括完整走法）

#### 1.2 扩展现有PGN API
- 已有 `/api/pgn-load` - 解析PGN内容
- 已有 `/api/pgn-navigate` - 棋谱导航
- 需要补充对局详情获取逻辑

### 第二阶段：前端Store扩展

#### 2.1 扩展 useGameStore
- 文件: `frontend/src/store/useGameStore.ts`
- 新增状态:
  - `gameMode: 'replay'` - 新增棋谱模式
  - `replayState` - 棋谱状态对象
    - `games: PGNGameInfo[]` - 对局列表
    - `currentIndex: number` - 当前步数
    - `totalMoves: number` - 总步数
    - `source: 'neo4j' | 'pgn'` - 来源
- 新增方法:
  - `loadGameFromNeo4j(gameId)` - 从数据库加载对局
  - `loadGameFromPGN(pgnContent)` - 从PGN加载
  - `navigateReplay(direction)` - 导航（prev/next/start/end/goto）
  - `exitReplay()` - 退出棋谱模式

### 第三阶段：前端UI组件

#### 3.1 新增棋谱选择面板组件
- 文件: `frontend/src/components/ReplayPanel.tsx`
- 功能:
  - Tab切换: "数据库对局" / "导入PGN"
  - 搜索框（棋手名/赛事名）
  - 对局列表展示
  - PGN文件上传/粘贴

#### 3.2 新增棋谱导航组件
- 文件: `frontend/src/components/ReplayNavigator.tsx`
- 功能:
  - 步数显示: "第 X / Y 步"
  - 导航按钮: ⏮️ ⏪ ▶️ ⏭️
  - 进度条（可拖拽跳转）
  - 当前走法显示

#### 3.3 修改主界面
- 文件: `frontend/src/App.tsx`
- 新增游戏模式按钮: "📚 打棋谱"
- 棋谱模式下显示专用面板

### 第四阶段：API服务层

#### 4.1 扩展 api.ts
- 文件: `frontend/src/services/api.ts`
- 新增接口:
  - `searchGames(params)` - 搜索对局
  - `getGameDetail(gameId)` - 获取对局详情

## 交互流程

### 从数据库选择对局
1. 点击"打棋谱"模式
2. 在搜索框输入棋手名（如"许银川"）
3. 显示匹配的对局列表
4. 点击选择对局
5. 棋盘显示初始局面
6. 使用导航按钮逐步浏览

### 导入PGN文件
1. 点击"导入PGN"标签
2. 粘贴PGN内容或上传文件
3. 解析后显示对局列表
4. 选择对局开始浏览

## 技术要点

1. **Neo4j查询优化**: 使用索引加速棋手名搜索
2. **PGN解析**: 复用现有 `parse_pgn_content` 函数
3. **状态管理**: 棋谱模式独立状态，不影响其他模式
4. **响应式设计**: 面板可折叠，适配不同屏幕
